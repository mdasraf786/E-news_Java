**📰 E-News Website
📌 Project Overview**

The E-News Website is a web-based application built using Java (JSP/Servlets) and MySQL that allows users and administrators to share, manage, and interact with news happening around them. The platform provides an interactive environment where users can upload news articles, like, comment, and engage with other users’ content.

The system ensures that all activities are monitored and controlled by an admin, who has complete authority over the website’s functionalities.

**✨ Features
👥 User Features**

Register and log in to the platform.

Upload and share local news with title, description, and images.

Like and comment on news shared by others.

Delete their own comments if needed.

Like comments from other users to show engagement.

View all news posted by the community.
**
👨‍💼 Admin Features**

Full access to the website.

Manage users (approve, block, or remove).

Approve, edit, or delete any news article.

Monitor likes and comments across the platform.

Ensure community guidelines are followed.

🛠️ Tech Stack

Frontend: JSP, HTML, CSS, JavaScript, Bootstrap

Backend: Java (Servlets, JSP)

Database: MySQL

Server: Apache Tomcat
**
🚀 How It Works**

Users sign up and log in.

They can upload news articles with details and media.

Other users can like and comment on the news.

Comments can also receive likes for higher engagement.

The admin monitors all activity and has the final authority to remove inappropriate content.

**🎯 Use Cases**

A platform for local community news sharing.

Students can use it as a Java + MySQL project for practice.

Small organizations or institutions can adapt it for internal news sharing.
